# S4 Tetrahedral Symmetry Viewer

正四面体の全対称群と4次対称群 `S4` の対応を観察するアプリです。

## 操作

- 左の24ボタン: 現在の姿勢へ対応する置換を続けて作用（アニメーション中の入力は順番に実行）
- `e`: 累積した作用をリセットして恒等姿勢へ戻る
- `Conjugacy class overlays`: 各共役類の行き先を一括表示・非表示
- `Group mode`: `S4`、`A4`、`V4` の表示・作用モードを切り替え
- `Individual region visibility`: 群モードの基本領域単位で、各位置の固定側と動く側をペア表示。S4では24個×1室、A4では12個×2室、V4では4個×6室のトグル構成
- `Keep original pose`: 恒等姿勢を半透明で残す
- 画面ドラッグ: カメラを正四面体の周囲で回転
- マウスホイール: ズーム
- `Auto rotation` スライダー: 水平オート回転（負値で逆回転）
- `Auto rotation enabled`: オート回転を一時停止・再開
- `Show rotation axis / reflection plane`: アニメーション中の回転軸・鏡映面を表示。4-cycleでは両方を同時表示
- Camera pose の `Save` / `Load`: カメラ姿勢を端末内へ保存・復元
- Camera pose の `Copy`: 現在姿勢をJSONテキストとしてクリップボードへコピー
- Camera pose のテキスト欄 + `Apply`: JSONテキストからカメラ姿勢を復元

置換の積は、新しく押した元を現在の元へ左から作用させます。例えば `(1234)` を2回押すと、累積結果は `(13)(24)` です。

`Right multiply` ボタンをONにすると作用方向を右積へ切り替えます。姿勢 `a` で `b` を押した場合、OFFでは `b · a`、ONでは `a · b` です。個別表示中の複合領域も、A4では `{g,g(12)}` の2室、V4では同一面の右側6室を一組のまま同時に右積します。作用中は切替できません。

図形の下には現在の元が表示されます。姿勢 `a` に元 `b` を作用して `c` へ移るアニメーション中は `b · a = c`、完了後は `c` と表示されます。`e` を押した場合は表示をすぐ `e` に戻します。

頂点番号は、固定姿勢が小さめで頂点の左上、動く姿勢が大きめで右上に表示されます。カメラの向きが変わっても画面上の左右関係を保ちます。

## 正規部分群モード

- `S4`: 1個の旗三角形を基本領域とし、24元を使用
- `A4`: 元の旗三角形と `(12)` の像を合わせた2個を基本領域とし、偶置換12元だけを使用
- `V4`: 同じ面を共有する6個の旗三角形を基本領域とし、`e` と3個の二重互換だけを使用

共役類は選択中の部分群の内部で再計算されます。そのため `A4` では8個の3-cycleが4個ずつの2共役類に分裂し、可換群 `V4` では4元がそれぞれ単独の共役類として表示されます。複数の旗三角形からなる基本領域では、先頭以外を暗い色で表示します。

左側の操作パネルはマウスホイールまたは縦スクロールバーで移動できます。

置換は頂点番号 `1..4` に作用します。偶置換は回転です。奇置換のうち互換は鏡映、4-cycle は鏡映と90度回転の合成です。3次元では向きを保つ姿勢から向きを反転する姿勢へ剛体のまま連続移動できないため、鏡映アニメーションは途中で鏡面方向につぶれる補間になっています。

基本領域は次の3点を結ぶ両面三角形です。

- 頂点 `(1, 1, 1)`
- 辺の中心 `(1, 0, 0)`
- 面の中心 `(1/3, 1/3, -1/3)`

24個の像は内部を重ならずに正四面体の境界を分割し、それぞれが `S4` の元と一対一に対応します。
